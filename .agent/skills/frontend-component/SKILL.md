# Frontend Component Generator

## Description

Generates a production-ready React component following FAANG standards.

## Usage

Agent will use this skill when creating new components.

## Steps

1. Ask for component name and purpose
2. Generate TypeScript interface
3. Create component file with memo wrapper
4. Add JSDoc documentation
5. Add error handling
6. Add loading states
7. Add accessibility features
8. Create test file
9. Update exports

## Output

- Component file in src/components/[feature]/[Name].tsx
- Test file in **tests**/[Name].test.tsx
- Updated exports in src/components/index.ts
